# Rust Rangers: Corrosion Island

An interactive 3D educational game about corrosion. Explore the island, investigate how water, oxygen, and salt affect corrosion, run experiments on metal samples, and record evidence in the lab notebook.

## Play

Open [`index.html`](./index.html) in a modern browser. The game and its 3D engine are bundled in the HTML file, so ordinary gameplay does not need a build step or external assets. WebXR/AR/VR features require an HTTPS-hosted page and compatible hardware; standard 3D gameplay does not.

## Controls

- Move with **WASD** or the **arrow keys**.
- Use **Space** to jump.
- Select tools with **1–6** or the on-screen tool buttons.
- Use the on-screen touch controls on mobile.

The detailed original file is also kept as [`Rust_Rangers_Corrosion_Island_FULL_AUDITED.html`](./Rust_Rangers_Corrosion_Island_FULL_AUDITED.html).
